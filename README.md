# AstrBot 同花顺问财插件

接入同花顺问财（iFinD/Wencai）接口，支持通过自然语言在 AstrBot 中查询股票选股逻辑、实时行情和基本面数据。

## ✨ 功能特性

- **自然语言选股**：支持如 "连续涨停板"、"市盈率小于20且业绩增长" 等复杂逻辑查询。
- **数据可视化**：自动将查询结果转换为清晰的 Markdown 表格。
- **智能清洗**：自动过滤 HTML 标签，提取核心文本信息。
- **多格式支持**：兼容 DataFrame 表格数据和百科类文本数据。

## 📦 安装

### 1. 安装插件

将本项目克隆或下载到 AstrBot 的 `data/plugins/` 目录下：

```bash
cd data/plugins
git clone https://github.com/fuchaohan/astrbot_plugin_wencai
```

### 2. 安装依赖

**重要**：本插件依赖 `pywencai`，该库需要 **Node.js** 环境来生成加密参数。

1.  **安装 Node.js**：请确保你的服务器/容器已安装 Node.js (推荐 v16+)。
    -   验证：`node -v`
2.  **安装 Python 库**：
    ```bash
    pip install -r requirements.txt
    ```

### 3. 重启 AstrBot

重启 AstrBot 后，插件将自动加载。

## 📖 使用方法

在聊天窗口发送指令：

| 指令 | 示例 | 说明 |
| :--- | :--- | :--- |
| `/问财 <问题>` | `/问财 连续涨停板` | 查询选股逻辑或数据 |

**示例查询：**

- `/问财 贵州茅台的主营业务`
- `/问财 2024年净利润增长率大于50%的医药股`
- `/问财 这里的最新收盘价` (在群聊中上下文)
- `/问财 连续3天缩量下跌`

## ⚠️ 注意事项

1.  **Node.js 环境**：必须安装 Node.js，否则无法获取数据。
2.  **接口限流**：问财接口对高频请求有限制，请避免短时间内大量连续查询。
3.  **数据延迟**：由于涉及加密参数计算和网络请求，回复可能会有 2-5 秒的延迟。
